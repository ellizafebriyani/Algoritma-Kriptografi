This project is a web-based cryptography application developed using Python, Flask, HTML, CSS, and JavaScript. It provides an interactive platform for learning and applying various classical cryptographic algorithms, including Vigenère Cipher, Full Vigenère Cipher, Auto-Key Vigenère Cipher, Extended Vigenère Cipher, Playfair Cipher, Affine Cipher, Hill Cipher, and Super Encryption. Users can encrypt and decrypt text through a simple interface, upload files for processing, and view the generated results instantly. The application is designed to help students understand encryption concepts while offering practical tools for secure text transformation and cryptography experimentation.
